# [要件プロンプト] クリップボード自動監視トグル・ウィンドウライフサイクル・システムトレイ連動仕様の実装

## 1. 目的 & スコープ

本仕様は、Windows 向け AI 翻訳アプリ「Copy-lot」における **「クリップボード自動監視トグル」「ウィンドウ表示状態（最小化・システムトレイ常駐）」「API キー正当性」を連動させた監視ライフサイクル制御** の詳細設計および実装要件を定義する。

特定レイヤー（UI のみ、Win32 のみ）に依存したアドホックな制御を排除し、Riverpod による単方向データフローとレイヤードアーキテクチャに基づき、破綻のない状態管理とネイティブ連携を実現する。

---

## 2. 状態遷移モデル & 実効監視ロジック

### 2.1 実効監視条件（三条件の論理積）

Win32 API（`AddClipboardFormatListener`）による実効的なクリップボード監視状態（`isListening`）は、以下の3つの条件がすべて満たされた場合のみ有効（ON）となる。

$$\text{実効監視状態 (isListening)} = (\text{ウィンドウ表示中}) \land (\text{自動監視トグル == ON}) \land (\text{API キー正当性確認済み})$$

いずれか1つでも条件を満たさない場合、ネイティブリスナーは解除され **完全停止** する。

### 2.2 状態遷移テーブル

| イベント / シナリオ | ウィンドウ状態 | 自動監視トグル | API キー有効性 | 実効監視状態 (Win32) | 挙動詳細 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **アプリ初回起動時** | 表示 | **OFF (初期値)** | 有効 / 無効 | **停止** | 永続化せず、起動毎に必ず OFF から開始。 |
| **API キー未設定/無効時** | 表示 | **OFF (固定)** | 無効 | **停止** | トグルスイッチは無効化（Disabled）され操作不可。 |
| **ユーザーがトグルを ON** | 表示 | **ON** | 有効 | **監視中** | 即座に現在のクリップボードテキストを参照し、適合すれば翻訳実行。以降の更新も監視。 |
| **ユーザーがトグルを OFF** | 表示 | **OFF** | 有効 | **停止** | リスナーを即座に解除。自動翻訳は停止するが、手動ペーストによる翻訳は受付可能。 |
| **手動ペースト実行** | 表示 | OFF / ON | 有効 | - | クリップボードからテキストを読み込み、即座に言語判定・翻訳を実行。 |
| **最小化 (`_`) または「×」押下** | **非表示 (トレイ格納)** | 直前状態を保持 | 有効 | **完全停止** | ウィンドウを非表示化しトレイへ格納。トグル状態に関わらずリスナーを解除。 |
| **トレイからウィンドウ復帰** | **表示** | **直前状態を復元** | 有効 | **トグル依存** | 格納前のトグルが ON であれば即座にリスナー再登録し、現在のクリップボードテキストを参照して翻訳実行。OFF であれば停止維持。 |
| **トレイメニュー「終了」** | - | - | - | **破棄** | リスナー完全解除、トレイアイコン破棄、アプリプロセス終了。 |

## 3. 機能要件

### 3.1 自動監視トグル制御
1. **初期値と非永続化:**
   - アプリ起動時の自動監視トグル初期値は常に **OFF** とする。
   - 本設定はローカルストレージに永続化せず、アプリプロセスのライフサイクルに合わせて毎回リセットする（機密テキスト等の意図しない誤通信を防止するセーフティ設計）。
2. **API キーガード連動:**
   - API キーが未設定、または接続確認が完了していない場合はトグルを無効化（Disabled）とする。
3. **トグル ON 移行時の即時評価:**
   - ユーザーがトグルを OFF から ON へ切り替えた瞬間、現在のクリップボードテキスト（プレーンテキスト）を取得する。
   - テキストガード（空文字・重複・文字数制限）および言語適合ガード（日→英 / 英→日）を満たす場合、即座に翻訳 API を呼び出す。

### 3.2 システムトレイ格納 & ウィンドウ連動
1. **ウィンドウ閉じる・最小化のインターセプト:**
   - ウィンドウの「×」ボタンおよびタイトルバーの「`_`（最小化）」ボタン押下時は、OS プロセスを終了・タスクバー最小化せず、**ウィンドウを非表示にしてシステムトレイへ格納**する。
   - タスクバー領域を占有せず、通知領域（システムトレイ）アイコンとして常駐する。
2. **トレイ格納時の完全停止:**
   - トレイ格納（ウィンドウ非表示）を検知した時点で、Win32 クリップボードリスナー（`RemoveClipboardFormatListener`）を呼び出し、バックグラウンドでの不要な CPU/メモリ消費および監視を完全に停止する。
   - このとき、メモリ上の自動監視トグル状態（ON または OFF）は破棄せず保持する。
3. **トレイからの復帰と自動再開:**
   - トレイアイコンのクリック、またはトレイメニューの「表示」選択によりウィンドウを再表示する。
   - 保持していたトグル状態を復元し、トグルが ON であった場合は以下を実行する：
     1. クリップボードリスナーを再登録する。
     2. 復帰時点のクリップボードテキストを取得し、条件を満たせば即座に翻訳を実行する。

### 3.3 自動監視 OFF 時の手動ペースト機能
1. **手動ペーストの受容:**
   - 自動監視が OFF の状態であっても、ユーザーはメイン画面の「クリップボードから貼り付け」ボタン（またはショートカット等）により手動で翻訳を実行できる。
2. **処理フロー:**
   - 手動ペースト実行時、クリップボードデータソースからテキストを取得し、自動監視と同様のデータガード・言語適合チェックを経て翻訳を実行する。

## 4. アーキテクチャ & レイヤー設計

```text
lib/
├── domain/
│   └── models/
│       └── clipboard_state.dart     # isAutoMonitoringEnabled, isWindowVisible 等を保持
├── data/
│   └── datasources/
│       ├── win32_clipboard_datasource.dart # Add/RemoveClipboardFormatListener FFI
│       └── window_tray_datasource.dart     # ウィンドウ表示/非表示・トレイ管理
├── presentation/
│   ├── providers/
│   │   └── clipboard_provider.dart  # 実効監視状態の計算・ライフサイクルイベント購読
│   ├── screens/
│   │   └── main_screen.dart         # 自動監視トグル・手動ペーストボタン・ウィンドウ連動
│   └── widgets/
│       └── auto_monitor_switch.dart # アニメーション付きトグルスイッチ部品
```

1. **`ClipboardState` (Domain Model):**
   - `isAutoMonitoringEnabled` (bool): UI のトグルスイッチ状態（デフォルト `false`）
   - `isWindowVisible` (bool): ウィンドウが表示されているか（デフォルト `true`）
   - `isListening` (bool): 実効的な監視状態（計算プロパティ: `isAutoMonitoringEnabled && isWindowVisible && hasValidApiKey`）
   - `currentText` (String): 現在表示中の原文テキスト
2. **`ClipboardNotifier` (Presentation Notifier):**
   - トグル切り替えメソッド `toggleAutoMonitoring(bool enabled)`
   - ウィンドウ可視性変更メソッド `setWindowVisibility(bool visible)`
   - 手動ペースト実行メソッド `pasteAndTranslate()`
   - 実効監視状態の変化を監視し、`ClipboardRepository` の `startListening()` / `stopListening()` を過不足なく呼び出す。

## 5. 検証基準 & テストケース

1. **初期状態テスト:**
   - アプリ起動直後、自動監視トグルが OFF であり、クリップボードリスナーが動作していないこと。
2. **トグル切り替え & 即時翻訳テスト:**
   - クリップボードに有効なテキストが存在する状態でトグルを ON にした際、即座にテキストが取り込まれ翻訳がトリガーされること。
3. **トレイ格納 & 停止テスト:**
   - ウィンドウをトレイへ格納（非表示化）した際、Win32 リスナーが停止（`RemoveClipboardFormatListener`）すること。
   - 格納中に他アプリでコピー操作を行っても、アプリが反応しないこと。
4. **トレイ復帰 & 状態維持テスト:**
   - トグル ON の状態でトレイ格納 $\to$ 復帰した際、トグルが ON のまま復元され、リスナーが再開されること。
   - トグル OFF の状態でトレイ格納 $\to$ 復帰した際、停止状態が維持されること。
5. **手動ペーストテスト:**
   - トグル OFF の状態で手動ペーストボタンを押下した際、現在のクリップボードテキストが正常に取り込まれ翻訳されること。
6. **API キーガードテスト:**
   - API キーが空または無効な場合、トグル操作が無効化（Disabled）されること。
